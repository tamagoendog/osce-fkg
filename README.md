# Mesin OSCE FKG USU

App belajar OSCE Blok 24 (ART, PFS, PRR) untuk mahasiswa FKG USU. Isinya kartu nalar ("tebak dulu"), latihan susun urutan, lisan 2/1/0, kasus, kuis, dan contekan.

## Pasang di HP
- **iPhone:** buka link di Safari → Share → Add to Home Screen.
- **Android:** buka link di Chrome → Install app.

Setelah sekali dibuka, app jalan tanpa internet. Progres tersimpan di HP masing-masing.

## Sumber materi
Buku Skills Lab Blok 24 FKG USU, rangkuman OSCE Konservasi Blok 24, dan catatan kuliah. Beberapa sumber tidak sepakat (bonding PRR A, nomor bur PRR B, liner PRR C); konfirmasi ke dosen.

## Update materi
Edit `index.html`, lalu naikkan versi `CACHE` di `sw.js` (misalnya `osce-fkg-v2`) supaya semua HP mengambil versi baru.
